# 🏗️ 3D地板墙体编辑器

基于 **Vue 3 + Three.js** 的纯前端三维建模平台，支持平面图上传、地板区域绘制、墙体线段绘制及3D模型自动生成。

---

## 🎯 核心功能

| 功能 | 描述 |
|------|------|
| 📤 **上传平面图** | 支持 JPG/PNG/SVG 格式，平铺在 XZ 平面 (Y=0) |
| 📥 **加载默认平面图** | 一键加载内置示例户型图 |
| 🖍️ **绘制地面** | 鼠标点击标记多边形顶点，双击完成闭合 |
| 🧱 **绘制墙体** | 双击设置起点，再双击设置终点 |
| 🏠 **生成3D模型** | 地板(厚度5,透明蓝)+ 墙体(厚度4,高度10) |

---

## 🛠 技术栈

| 层级 | 技术 |
|------|------|
| 前端框架 | Vue 3 + TypeScript + Vite 5 |
| 3D引擎 | Three.js 0.162 |
| 状态管理 | Pinia |
| 样式方案 | CSS Variables + Modern CSS |

## 🎮 操作指南

| 操作 | 功能 |
|------|------|
| 🖱️ **左键拖动** | 旋转视角 |
| 🖱️ **右键拖动** | 平移视角 |
| 🖱️ **滚轮** | 缩放视角 |

## 🔧 模型参数

| 模型 | 参数 | 材质 |
|------|------|------|
| 地板 | 厚度: 5 | 透明浅蓝色 (opacity: 0.6) |
| 墙体 | 厚度: 4, 高度: 10 | 灰色实体 |
